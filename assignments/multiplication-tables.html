Multiplication tables 1 to 30

Question: Write a JavaScript program to display multiplication tables from 1 to 30 in an HTML page.

View source code (HTML + JavaScript)
<div id="out" class="tables"></div>

<script>
const out = document.getElementById("out");
for (let n = 1; n <= 30; n++) {
  let html = "<div><h4>Table of " + n + "</h4>";
  for (let i = 1; i <= 10; i++) {
    html += n + " x " + i + " = " + (n * i) + "<br>";
  }
  out.innerHTML += html + "</div>";
}
</script>
