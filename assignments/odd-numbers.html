Odd numbers 1 to 100

Question: Write a JavaScript program to display all odd numbers between 1 and 100 in an HTML page.

View source code (HTML + JavaScript)
<div id="out" class="chips"></div>
<p id="count"></p>

<script>
const out = document.getElementById("out");
let count = 0;
for (let i = 1; i <= 100; i++) {
  if (i % 2 !== 0) {
    out.innerHTML += '<span class="chip">' + i + "</span>";
    count++;
  }
}
document.getElementById("count").textContent = "Total odd numbers: " + count;
</script>
