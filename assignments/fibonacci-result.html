Fibonacci series (page 2 of 2)

Question: Create two HTML pages. When the user clicks the Show button on the first page, display the first 10 terms of the Fibonacci series in a text box on the second page. Provide a Back button to return to the first page.

<p>This is <strong>page 2</strong>. First 10 terms of the Fibonacci series:</p>
<label for="fib">Fibonacci series</label>
<input id="fib" readonly>
<a class="btn alt" id="back" href="fibonacci-start.html">&larr; Back</a>

<script>
let a = 0, b = 1, terms = [];
for (let i = 0; i < 10; i++) {
  terms.push(a);
  const next = a + b;
  a = b;
  b = next;
}
document.getElementById("fib").value = terms.join(", ");
document.getElementById("back").addEventListener("click", function (e) {
  e.preventDefault();
  window.location.href = "fibonacci-start.html";   // return to the first page
});
</script>
