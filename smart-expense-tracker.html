03 / PERSONAL FINANCE

Smart Expense Tracker

HTML5CSS3Vanilla JavaScriptCanvas APIlocalStorage

Overview

Smart Expense Tracker is a responsive personal finance dashboard built with vanilla web technologies. It helps users record and manage income and expenses, set monthly budgets, filter transaction history and understand spending patterns through visual charts. All data is stored privately in the browser using localStorage.

Key Features

  • Add, edit, delete and validate income and expense transactions
  • View balance, income, expenses and savings rate by month or overall
  • Set monthly budgets with usage progress and warning indicators
  • Interactive category doughnut chart and six-month comparison chart
  • Search and filter transactions by title, type and category
  • Load sample data, clear records and export transactions to CSV
