SMART EXPENSE TRACKER

Open index.html in any browser (or use VS Code Live Server). No server or install needed.
Files: index.html, style.css, app.js

Features
- Add, edit, delete income and expense transactions (with validation)
- Summary: balance, income, expenses, savings rate (per month or all time)
- Monthly budget with progress bar and warnings
- Spending-by-category doughnut chart and 6-month income vs expense chart (HTML5 Canvas)
- Search and filter by type and category
- Export all transactions to CSV
- "Load sample data" button for a quick demo
- Data is saved in the browser (localStorage), so it stays after refresh

Tech: HTML5, CSS3, vanilla JavaScript, Canvas API, localStorage
